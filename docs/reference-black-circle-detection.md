# 黑圈检测算法参考

## 算法概述

**算法名称**：black-filled-ellipse/v1

**用途**：从场景定位参考图中检测黑色填充的椭圆定位标记，用于确定宠物交互区域。

**原型验证成功率**：16/16 (100%)

**原型来源**：Issue #12 - 原型验证双场景共享环境与黑圈定位链路

---

## 算法步骤

### 1. 图像预处理

- 转换为灰度图
- 应用阈值分割提取黑色区域（阈值通常为 50-60）

### 2. 轮廓检测

- 使用 OpenCV `findContours` 检测所有黑色区域轮廓
- 过滤掉面积过小的噪声（最小面积阈值可配置）

### 3. 椭圆拟合

对每个候选轮廓：
- 使用 `fitEllipse` 拟合最佳椭圆
- 计算拟合质量（轮廓点到椭圆的距离方差）
- 筛选出拟合质量最佳的椭圆

### 4. 形状验证

验证候选椭圆是否满足定位标记特征：
- **长短轴比例**：接近 1（圆形）或在合理范围内（1:1.2 以内）
- **填充度**：内部黑色像素占比 > 85%
- **边缘清晰度**：边缘梯度强度足够高
- **尺寸范围**：半径在合理范围内（如 20-200 像素）

### 5. 结果输出

返回检测到的椭圆参数：
- **中心坐标** (center_x, center_y)
- **半径** (radius_px)
- **坐标空间**：pixel_top_left 或 pixel_bottom_left
- **画布尺寸** (canvas_width, canvas_height)

---

## 关键参数

| 参数名称 | 默认值 | 说明 |
|---------|--------|------|
| `threshold` | 50 | 黑色区域分割阈值（0-255） |
| `min_area` | 100 | 最小轮廓面积（像素²） |
| `max_area` | 50000 | 最大轮廓面积（像素²） |
| `aspect_ratio_tolerance` | 0.2 | 长短轴比例容差（偏离圆形的程度） |
| `fill_ratio_threshold` | 0.85 | 内部填充比例阈值 |
| `min_radius` | 20 | 最小半径（像素） |
| `max_radius` | 200 | 最大半径（像素） |

## 实施建议

### T6 实施时的考虑事项

1. **错误处理**
   - 未检测到黑圈：返回错误，重试生成定位参考图
   - 检测到多个候选：选择最接近画面中心的
   - 检测到的圆超出边界：返回错误，需要重新生成

2. **性能优化**
   - 可以先降采样图像加快处理速度
   - 结果需要按原始分辨率缩放回去

3. **鲁棒性增强**
   - 支持不同光照条件（调整阈值）
   - 支持轻微椭圆变形（放宽长短轴比例容差）
   - 支持不完美填充（降低填充比例阈值）

4. **测试覆盖**
   - 标准圆形黑圈（基准测试）
   - 轻微椭圆形（容差测试）
   - 边界情况（超出画布、过小、过大）
   - 噪声干扰（多个黑色区域）
