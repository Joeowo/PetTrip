## ADR 模板

每个 ADR 应包含：

1. **Status**: Accepted | Superseded | Deprecated
2. **Context**: 决策背景和问题陈述
3. **Decision**: 具体决策内容
4. **Consequences**: 正面影响和负面代价
5. **Alternatives Considered**: 被否决的备选方案及原因
6. **References**: 相关 issues、原型验证、wayfinder tickets
