# Pilot4MVP2 Agent Service 会话 6 交接

本文档记录会话 6“持久化与恢复”的实现、验收和 Git 边界。实现细节以代码、规格和脱敏证据为准。

## 当前结论

会话 6 已经通过受控跨进程验收：

- 同一 Session 完成两轮对话。
- 外部 API 客户端读取消息历史、已完成 Run 和生成图片引用。
- 停止并重新启动服务后，已完成 Run 和消息历史保持一致。
- 生成图片重启前后的字节数均为 `161`，SHA-256 均为
  `7b849cb70adfc612fa0400f80213be4668a5d97e7eaae746a95ef653681e4df3`。
- 在 Provider 执行期间强制终止服务后，遗留 `running` Run 进入
  `failed(SERVICE_RESTARTED)`。
- 遗留 Run 的受控 Provider 调用次数在恢复前为 `1`，恢复后仍为 `1`，没有自动重复调用；
  `server/provider-calls.jsonl` 保留可独立复查的原始受控调用记录。
- 同一 Session 可以继续创建新 Run，新 Run 成功完成。
- 验收驱动只调用 HTTP 辅助函数；独立 staged review 确认它没有导入 `Storage`，也没有直接读取
  SQLite 或服务端业务文件来判断结果。

本次使用受控 Provider 只验证 SQLite、文件目录和服务生命周期边界。会话 5 已经提供真实
Chat/Vision 和图片 Provider 的组合输出证据；会话 6 不宣称真实 Provider 调用在进程重启中可
恢复或自动重试。

- `pilot4mvp2/scripts/session6_controlled_server.py`
  - 受控 Chat Provider、结构化输出和固定 PNG Image Provider。
  - 支持延迟 Provider 和跨进程调用日志。
- `pilot4mvp2/scripts/verify_session6.py`
  - 启动、停止、强制终止和重新启动独立服务进程。
  - 通过 HTTP API 完成两轮对话、结果重读、图片下载哈希校验、遗留 Run 恢复和新 Run 继续。
  - 只有 `passed: true` 时发布证据；拒绝覆盖已有证据目录。
- `pilot4mvp2/tests/test_verify_session6.py`
  - 验收发布保护和完整跨进程恢复验收测试。
- `pilot4mvp2/flowise-unity-pilot-spec.md`
  - 标记会话 6 恢复结论和完成定义中的两项恢复条件。
