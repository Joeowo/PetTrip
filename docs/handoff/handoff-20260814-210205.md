## 配置契约

图片 Provider 的唯一外部环境变量名称是：

```text
IMAGES_BASE_URL
IMAGES_API_KEY
IMAGES_MODEL
```

不要重新引入 `IMAGE_BASE_URL`、`IMAGE_API_KEY` 或 `IMAGE_MODEL` 别名。Python 内部字段仍为
`settings.image_base_url`、`settings.image_api_key` 和 `settings.image_model`。

图片生成的非身份运行参数继续使用 `IMAGE_TIMEOUT`、`IMAGE_GENERATION_PATH`、
`IMAGE_CANVAS_WIDTH` 等名称。

服务从原仓库的 gitignored `.env.local` 读取 Chat 和 Images Provider 配置。任何 Key、完整
Provider URL 或公网 Base URL 都不得写入 Git、日志或证据。

## API 交付

外部客户端文档位于：

`pilot4mvp2/pettrip-agent-api.md`

文档覆盖：

- Bearer 鉴权和 Session；
- PNG/JPEG 上传和鉴权下载；
- 文本和 Vision Run；
- `scene_draft` `0.1` 结构化输出；
- 图片生成 Run 和 `output.attachments`；
- 文本、结构化数据和图片组合输出；
- 状态轮询、错误码和 SHA-256 校验；
- Postman、Apifox、`curl.exe` 和后续 Unity 客户端约束。

公网图片部署验收工具位于：

`pilot4mvp2/scripts/verify_public_image_api.py`

它通过公网 HTTPS 创建一次图片 Run、轮询、鉴权下载两次，并校验 PNG、尺寸、字节数和哈希。

## 持续运行服务

Agent Service 和 Cloudflare Tunnel 以仓库外独立进程持续运行。运行状态位于：

```text
%LOCALAPPDATA%\PetTrip\AgentService\Session7\processes\
```

PID 文件：

- `agent-service.pid`
- `tunnel-launcher.pid`
- `cloudflared.pid`

私密配置文件：

- `pettrip-pilot-api-key.local`
- `public-base-url.local`

这些目录使用受保护的 Windows ACL。不要把文件内容打印到终端或聊天。

Agent Service 只监听 `127.0.0.1`；公网只通过 Tunnel 访问。Tunnel 运行时不要开放本地服务
端口或添加防火墙入站规则。
