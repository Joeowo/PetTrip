- Keep the external HTTP contract provider-neutral. Do not expose Flowise or
  Provider-specific response objects.
- Preserve Session, Run, file, and API-client ownership in SQLite.
- Never store image binaries, Base64, API keys, absolute paths, or raw Provider
  errors in SQLite, responses, logs, or evidence.
- Keep polling independently usable; SSE remains optional.
- Do not add Redis, Celery, Kafka, multi-agent orchestration, or Unity client
  changes.
- Continue using a dedicated worktree/feature branch. Commit to
  `feat/pilot4mvp2-agent`, then request review before any merge to `main`.
