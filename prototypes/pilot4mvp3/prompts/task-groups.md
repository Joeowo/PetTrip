# Mask 稳定性任务组 Prompt

所有场景图都使用以下共享前缀：

```text
Use case: stylized-concept
Asset type: 16:9 horizontal game travel scene, fixed camera
Style/medium: Neva-inspired hand-painted 2D storybook landscape; simplified expressive
shapes, clear silhouettes, muted gouache and pastel color blocks, restrained paper-and-brush
texture, cinematic horizontal staging; no photorealism, no 3D render, no generic anime background
Palette: follow the selected NEVA palette from docs/neva_palette_guide.html;
first two colors establish the emotional base, third color defines structure,
fourth color defines dark contours, fifth color is a small 5%-10% accent
Composition: clear foreground ground strip, readable midground landmark,
large atmospheric background, no UI, no text, no watermark, no people, no pet
Lighting: one consistent time of day and one consistent key-light direction;
keep shadows and material response coherent
```

固定 Mask 约束：画布短边的 14% 直径；黑色实心圆；每张 Mask 图只画一个圆；圆心放在目标元素旁边的合理承载面；不覆盖目标元素主体、不跨越天空或水面、不改变其他像素。

固定角色条件：

```text
参考角色：MYGO!!!!! 的若叶睦 Q 版形象；灰蓝短发和标志性发型轮廓，
青绿色眼睛，冷灰蓝服装，圆润 Q 版头身比，简化但可识别的五官；
保持同一角色身份、体型比例、发型、眼睛颜色和配色。
```

## G01：十二门徒海岸 / C08

视觉分析：多个海蚀柱是强垂直地标，海岸线提供低处承载面；适合测多相似目标和海岸边缘。

特征元素：

- E1：右侧前景的一根主海蚀柱与其下方岩岸。
- E2：左侧海蚀柱群旁的海岸步道/岩台。

场景 Prompt：

```text
基于十二门徒海岸的构图特征，生成一张纯场景横版旅行画面：前景是低矮的海岸草带和岩石地面，中景是清晰但不拥挤的海蚀柱群与一条靠近观景边缘的安全步道，后景是宽阔海面、浅色云层和远处海平线。保留 E1 主海蚀柱和 E2 海岸步道两个可互动地标，二者位置关系清楚；不出现任何角色、人物或文字；固定镜头，适合后续局部 Mask 编辑。
```

Mask E1：

```text
基于这张纯场景图，只在右侧主海蚀柱下方、靠近岩岸的安全地面放置一个直径为画布短边14%的黑色实心圆形 Mask，圆心位于角色脚底应站立的位置；不要覆盖海蚀柱主体、海面或天空；保持其他构图、光照、海岸线和色板完全不变。
```

Mask E2：

```text
基于这张纯场景图，只在左侧海岸步道靠近岩台的平坦地面放置一个直径为画布短边14%的黑色实心圆形 Mask；不要覆盖海蚀柱群、海面或步道主要边缘；保持其他构图、光照和色板完全不变。
```

角色编辑共同 Prompt：

```text
参考带黑色 Mask 的场景图，在黑色圆形 Mask 内生成一只 MYGO!!!!! 若叶睦 Q 版角色；角色主体和脚底必须完全落在 Mask 内，不能留下黑色圆；保持场景镜头、海蚀柱、海面和光照不变。唯一动作是角色在目标海岸地标旁轻轻探头观察海面；角色不越界、不增加第二只角色、不改变海蚀柱形状。
```
